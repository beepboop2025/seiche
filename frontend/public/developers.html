Claude Code · one command

Connect the hosted MCP

No package or API key. This installs the endpoint for your current Claude Code scope.

claude mcp add --transport http seiche https://api.seiche.info/mcp
Any URL-capable MCP client

Use the standard config

Clients that accept remote servers need only the URL. The server is stateless streamable HTTP.

{ "mcpServers": { "seiche": { "url": "https://api.seiche.info/mcp" } } }
REST · smallest assembled read

Fetch the gauge

A compact current contract for dashboards, alerts and risk pipelines. It is assembled from the board and can be slower on a cold rebuild; treat timeout or error as unavailable, never as calm.

curl --max-time 30 https://api.seiche.info/api/gauge
REST · money-market context

Open the USD desk or global atlas

The USD route exposes seven granular sections with exact-date formulas and simple explanations. The Atlas lists all 11 registered packs and 52 source-audited expansion records. Neither registration nor discovery is live coverage: a market may have an available benchmark, derived-only context with raw values withheld, only a policy anchor, or no eligible observation. Expansion rows carry source, benchmark type, rights caveat and review stage but no quote. Own-history statistics stay at each source's native cadence; licensing policy travels with the output.

curl https://api.seiche.info/api/money-markets curl https://api.seiche.info/api/v2/money-markets
REST + MCP · world markets

Join money, forex and capital

The versioned world-markets contract projects only completed Seiche state. It carries 22 public H.10 FX reference series, three dollar indexes, bounded macro-capital transmission, source clocks, canonical topic URLs and explicit gaps. REST and MCP accept the same seven section names; neither collects or fits at request time.

curl 'https://api.seiche.info/api/v2/world-markets?section=capital_markets' world_markets_context(section="capital_markets")
