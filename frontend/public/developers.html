Any URL-capable MCP client

Clients that accept remote servers need only the URL. The server is stateless streamable HTTP.

OpenAI Responses API · remote MCP

Ground a response in Seiche

The public tools are read-only, so this example allows their calls without a second approval round.

curl https://api.openai.com/v1/responses \ -H "Authorization: Bearer $OPENAI_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"gpt-5.6","tools":[{"type":"mcp","server_label":"seiche","server_url":"https://api.seiche.info/mcp","require_approval":"never"}],"input":"What does the current funding-stress gauge say, and how fresh is the evidence?"}'
