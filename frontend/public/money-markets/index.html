What Seiche can see across money markets

Seiche does not publish a universal world-economy score. It publishes a bounded evidence map: 11 registered monetary-area packs, six redistributable public benchmarks, one derived-only benchmark, one policy-only market, three explicit data gaps, and 52 source-audited discovery candidates. Registration, availability, validation, and evidence eligibility remain separate claims.

How to interpret it

Coverage is not a score

Each market is compared only with compatible local anchors and its own native-frequency history. Seiche does not rank unlike raw interest-rate levels across currencies, and it does not turn missing data into a calm reading.

What it can answer

Where public benchmark evidence exists

The receipt identifies the benchmark, observation date, official source, redistribution state, and current market-pack support boundary for each registered monetary area.

What it cannot answer

Whether the whole world is stressed

There is no universal score. Global Tide is unavailable because the required cross-basin FX swap basis evidence is absent. Six public benchmarks cannot stand in for the world economy.

Validation boundary

Reference is not evidence eligibility

The US pack is validating and the other registered packs are reference context. Zero of 11 packs in this receipt is supported or evidence-eligible for validated historical claims.

Rights boundary

Upstream rights travel with the data

AGPL-3.0-or-later covers Seiche code, not upstream data. Allowed values may be public. Derived-only raw levels remain withheld. Metadata-only inputs cannot enter public calculations.

Freshness boundary

Every series keeps its own clock

Daily, weekly, and event-driven releases are not upsampled into fake simultaneity. Use each observation's asof, publication time, knowledge time, expected cadence, and freshness status.

Discovery boundary

Fifty-two candidates are not live coverage

The nine-region expansion ledger records source research. Promotion requires methodology, point-in-time behavior, calendars, reliability, legal rights, and production operations to pass review.

Public retrieval

Use the page for meaning and the API for now

This page and its JSON twin preserve a fixed, citable 21 August receipt. The REST endpoints expose the current board and per-series clocks. The MCP endpoint exposes Seiche's public read-only tools; inspect tools/list for its current inventory.

For researchers and retrieval systems

Attach the evidence clock

  1. Use the catalog for identity and scope. Resolve stable market IDs, availability definitions, source rights, and the fixed coverage receipt.
  2. Use the live Atlas for current facts. Read its generated_at, then retain the selected observation's asof, source URL, cadence, and freshness state.
  3. Check evidence eligibility separately. A visible benchmark can still belong to a reference or validating pack with no supported historical claim.
  4. Cite distinct evidence objects for distinct claims. Link this page for scope, the live API for the reading, the official source for the underlying observation, and the methodology for Seiche's transformation.
