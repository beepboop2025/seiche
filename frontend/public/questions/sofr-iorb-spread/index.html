How is the spread calculated?

Subtract IORB from SOFR in percentage units, then multiply by 100. Here, (3.88 − 3.90) × 100 = −2 bp. One basis point is 0.01 percentage point. Comparing a new SOFR observation with an older IORB value can create a misleading spread, so Seiche uses dates shared by both series.

SOFR measures the cost of overnight borrowing secured by Treasury collateral. IORB is the rate the Federal Reserve pays on eligible reserve balances. They describe different instruments and counterparties, which is why their difference is informative but is not a risk-free arbitrage offer.

How should a researcher read it?

A value below zero means this broad Treasury repo rate is below IORB on the matched date. A value above zero means repo borrowing is more expensive than that administered reserve rate. Read the spread with reserve balances, repo volumes, distribution percentiles, facility use and calendar effects.

In the five observations from 28 September through 2 October in this capture, SOFR was above IORB on zero days. That is a description of the retained sample, not a prediction for the next session.

What this evidence cannot establish

  • This is public research, not an executable funding quote, a forecast or a bank-solvency assessment.
  • A positive spread is a price signal. It does not, by itself, identify a cause or prove aggregate reserve scarcity.
  • The reviewed daily observations are older than the page review. Missing observations are not forward-filled to create a “today” number.
