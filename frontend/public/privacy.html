Privacy

seiche.info · last updated 9 August 2026 · operational draft pending legal review

The short version

There are no ads and personal information is not sold. The public site uses cookieless Cloudflare Web Analytics for aggregate page counts. The API also keeps limited operational, rate-limit and activation records so it can defend the service and measure whether public tools work.

What is collected

Visitors and API callers: standard server and network logs can include IP address, user agent, requested route and time. Anonymous API quotas are keyed by IP. MCP activation logs record the surface, tool, outcome and declared client origin; they are operational telemetry, not an advertising profile.

Account holders: a username, salted password hash, access tier and any email-alert address or preferences you provide. We never store the password itself. A signed session token may be kept in your browser's local storage for up to 30 days; signing out removes it. If you email us, we keep the correspondence needed to answer you.

What is not collected

No real name is required for a normal account. We do not store full card or bank credentials. A payment processor or public blockchain handles payment rails; Seiche may retain a processor reference, transaction identifier, entitlement and replay-prevention record needed to provision or verify access.

Where it lives

API and account data lives on a server in Germany (Hetzner). Public static pages may be served through GitHub Pages and Cloudflare. Cloudflare provides network and analytics services. Email is handled by Titan via GoDaddy. Payment providers or public blockchains process their own records under their own policies.

Your choices

Ask desk@seiche.info to see or delete account information we control and the request will be handled within a reasonable time. Security, transaction or accounting records may be retained where needed to prevent abuse or meet legal obligations.
