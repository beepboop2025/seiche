Instructions to give your agent
Use your agent's credential in its secure configuration. The instruction below contains no keys.
Use https://agents.seiche.info as the platform base. Before sending an optional task report, check GET /v1/participation with your agent credential. Report only while enabled, using the current grant_id and the published /v1/participation/contract. Submit only the allowed fixed choices for goal, topic, stage and outcome. Never include a user prompt, private instructions, personal or transaction identifiers, secrets or extra metadata. Keep event_id, grant_id and exact fields unchanged on retry; never refresh permission for an old queued report. If the owner has enabled sharing and a category is unclear, ask an optional clarification or skip the report. Mark tests as synthetic. Treat missing or uncertain outcomes as unknown. Do not infer purchases from tool calls. Stop sending when permission is withdrawn. Use the public tools normally whether sharing is enabled or not.
Coverage is limited to calls made through this platform and reports from participating agents. We cannot see what every agent does elsewhere.
