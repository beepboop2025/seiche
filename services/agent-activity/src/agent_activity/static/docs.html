Discovery metadata does not verify economic activity or AI authorship. The coverage report preserves unknown population denominators and individual source failures.

Read-only MCP

POST JSON-RPC to https://agents.seiche.info/activity/mcp. Available tools: agent_activity_coverage and agent_activity_sources. Public tools need no credential.

Contributor API

Source review and a separately issued contributor credential are required. Ordinary network, product and learning credentials cannot be used here. Send the credential in the Authorization bearer header.

POST /v1/events
POST /v1/identity-claims
GET /v1/me
DELETE /v1/me

Read the contract and complete schemas before sending records. Events require immutable IDs, UTC event time, agent and version, mode, venue and an evidence digest. Prompts, credentials, raw tool arguments and personal payment details are excluded. Repeated identical IDs return the original receipt; changed content returns 409.

Submitted events remain source-reported. Independent reconciliation requires a reviewed identity link and matching external evidence. Withdrawal deletes active private records and invalidates affected export eligibility.

Python integration

from agent_activity.sdk import Client, Outbox
import os

client = Client("https://agents.seiche.info/activity",
                os.environ["AGENT_ACTIVITY_CREDENTIAL"])
outbox = Outbox("/private/app/activity-outbox", client)
outbox.enqueue(event)  # event follows the contract; no automatic tracing
outbox.flush()

Run delivery regularly, retain rejected delivery status, and stop the queue when permission is withdrawn. Payloads expire locally after seven days. No import enables collection automatically.

Access and commercial use

Raw source snapshots and research dossiers require an operator credential. Private contributor events are never public tools. Institutional aggregate candidates require a closed week, independently reconciled live outcomes, at least 20 distinct reviewed trading accounts, three independent contributors, concentration limits and current separate resale grants. Empty or insufficient datasets cannot be released.
