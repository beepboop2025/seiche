How to read this evidence
  1. Discovery: a source lists an identity or service.
  2. Attribution: a reviewed record links an agent to an account during a stated period.
  3. Observation: an independent source reports the action or outcome.
  4. Reconciliation: the submitted event matches that source, including quantity, side and time.
Missing links stay missing. Provider-reported usage, independent observations and contributor statements retain their separate meanings. Collection history begins with the recorded observation window; it is not a reconstruction of every earlier event.
